# Görsel yuvaları

Bu klasördeki SVG'ler sadece tasarım placeholder'ıdır. Kendi görsellerinle değiştirirken `index.html` içindeki dosya yollarını güncelle.

Tarayıcı performansı için AVIF veya WebP önerilir. Büyük görselleri mümkünse 500 KB altında tut ve yayımlama hakkın olmayan anime/sanatçı görsellerini kullanma.
